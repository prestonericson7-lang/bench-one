# Measurement output

Console output from real runs, kept because the numbers quoted in `docs/` are drawn from these files
and a figure with no trace back to its raw output is an assertion rather than a measurement.

The naming is terse because it was written at the bench: a letter for the experiment and a number for
the run, so `b_1.log` through `b_3.log` are three repeats of the same configuration. Repeats are kept
rather than averaged, because the spread is itself a result — a number that moves between runs is a
different kind of number from one that does not.

These are outputs, not inputs. Nothing reads them. Delete them and only the provenance is lost.
